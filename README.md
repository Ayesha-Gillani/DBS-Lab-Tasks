# DBS-Lab-Tasks-4th-Semester
Database Systems — Lab Work

Welcome to my Database Systems lab repository.

This repository contains my practical work, SQL queries, database exercises, and lab tasks completed during the semester. The work is organized lab-wise so that each lab can be easily viewed and understood.

About the Repository

The purpose of this repository is to keep all my Database Systems practical work in one place and to practice the concepts covered in the course using MySQL.

The labs gradually cover different areas of database design and SQL, starting from basic database operations and moving towards more advanced queries, relationships, normalization, joins, functions, and reporting.

Topics Covered

The repository includes practical work related to:

- Database and table creation
- Primary and foreign keys
- Constraints and relationships
- Data insertion and manipulation
- SQL filtering
- Sorting and searching data
- Scalar functions
- Aggregate functions
- "GROUP BY" and "HAVING"
- SQL joins
- Database normalization
- 1NF, 2NF and 3NF
- Subqueries and reporting queries
- Relational database concepts
- Practical database design and implementation

Learning Goals

Through these labs, I am developing practical understanding of how relational databases are created, managed, queried, and organized.

The main focus is not only on writing SQL queries but also on understanding how different database concepts work together in real-world database systems.

How to Use

1. Open the SQL file for the required lab.
2. Open it in MySQL Workbench or another compatible MySQL environment.
3. Run the database setup and table creation queries first, where provided.
4. Insert the required sample data.
5. Run the queries for the individual tasks.
6. Check the results in the SQL output.

Repository Purpose

This repository serves as a record of my practical learning and coursework for Database Systems. It will be updated as new labs and practical tasks are completed throughout the semester.
